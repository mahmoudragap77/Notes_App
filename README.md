 Notes App

A simple Android notes application built with Kotlin and Jetpack Compose, allowing users to create, view, edit, and delete notes.

✨ Features

Create and save notes.

View notes in a scrollable list.

Edit and delete existing notes.

Store notes locally using Room Database.

🛠️ Tech Stack

Kotlin

Jetpack Compose

Room Database

ViewModel

Kotlin Coroutines & Flow

JUnit & AndroidX Testing
